# ORYN

Production-minded multi-category ecommerce platform.

## Workspace

- `apps/mobile` — Expo / React Native customer application
- `apps/admin` — Admin web application
- `apps/api` — Node.js / Express API
- `packages/database` — Prisma + MySQL
- `packages/shared-types` — Shared TypeScript domain contracts
- `packages/validation` — Shared Zod validation schemas
- `packages/config` — Shared tooling configuration

## Development

Use Node.js LTS and pnpm 10.28.x.

```bash
pnpm install
pnpm dev
```
